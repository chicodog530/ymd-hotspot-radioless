# Branding Assets

This directory holds the YWD-Hotspot project artwork.

```text
ywd-hotspot-logo-master.png
    Original 1254x1254 RGBA source artwork supplied for the project.

ywd-hotspot-badge-256.webp
    256px optimized WebP derivative intended for lightweight WebUI/README use.
```

The current Alpha5 runtime WebUI has **not** been modified to display the logo yet. Keeping the badge here makes it available for a future UI build without changing the in-testing Alpha5 behavior.

For the Pi Zero dashboard, prefer the optimized WebP derivative rather than serving the multi-megabyte master PNG.
